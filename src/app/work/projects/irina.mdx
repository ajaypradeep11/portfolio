## Overview

**Tech Pack OS** is the next evolution of IRINA: a private studio workspace for converting garment references into technical specifications that a human operator can inspect, correct, and move toward production. The product now leads with an evidence-first principle - every construction claim is visibly marked as confirmed, proposed, awaiting review, or awaiting operator input.

That distinction matters in apparel engineering. A photograph can reveal a silhouette, seam, pocket, or collar, but it cannot reliably prove hidden construction, exact measurements, material behavior, or machine settings. Tech Pack OS keeps AI useful at the interpretation layer while deterministic geometry, explicit measurements, validation rules, and operator approval remain the authority for production output.

The workspace supports image-led and manual creation flows. A user can begin with garment evidence, review extracted construction details, edit a technical flat, resolve unanswered questions, validate pattern relationships, and prepare vector or cutter-oriented files without losing the reasoning behind each decision.

## Key Features

- **Evidence status system**: Separates source-confirmed details from proposals, open review items, and questions that require operator input, so generated claims never silently become production facts.
- **Image-to-specification workflow**: Guides a reference through intake, interpretation, technical-flat review, pattern development, and export while preserving the original evidence.
- **Parametric technical flats**: Front and back garment views are built from editable panels, collars, yokes, sleeves, cuffs, plackets, pockets, stitch lines, and measurement guides.
- **Reusable construction components**: Components keep stable identities, parameters, placement, revision history, validation state, and downstream pattern output.
- **Deterministic geometry engine**: Measurement-driven formulas generate semantic pattern pieces with seam allowances, notches, grainlines, internal lines, and linked construction checks.
- **Production handoff**: Supports physical-size SVG and PDF output, layered DXF, and guarded cutter-oriented exports with clear operator review and simulation requirements.
- **Private studio access**: Authentication keeps customer references and specifications inside a studio workspace while supporting resumable project work.

## Technologies Used

- **Next.js, React, and TypeScript** for the authenticated studio, evidence workflow, technical-flat editor, inspectors, and export surfaces.
- **NestJS and TypeScript** for reference intake, component commands, document evaluation, pattern drafting, validation, and file-generation APIs.
- **SVG-based geometry** for crisp, directly editable technical drawings and shared browser/export primitives.
- **Firebase Authentication and App Hosting** for private access and deployment, with backend services running on Google Cloud Run.
- **PDF and DXF generation** for calibrated production documents and downstream CAD/CutWorks workflows.
- **Automated unit and API testing** around formulas, validation, image inspection, component commands, pattern documents, and exporters.

- Designed and implemented the private studio experience, including authentication, project entry points, reference intake, workflow state, and production-file progression.

- Added defense-in-depth image validation in both the browser and API before references enter the workspace.

## Challenges and Learnings

The hardest product decision was defining where AI must stop. Garment photos contain perspective distortion, folds, styling, and hidden seams, so an apparently confident model output may still be unsuitable for manufacturing. The evidence ledger makes uncertainty part of the interface: a proposal remains a proposal until an operator confirms it.

The second challenge was keeping one edit coherent across multiple representations. Moving a pocket can affect the flat sketch, component revision, panel-containment checks, pattern geometry, measurements, fabric estimates, and exports. Stable component identities and domain events let those consumers stay synchronized without tightly coupling every UI surface.

Production export also required restraint. Cutter behavior depends on controller, firmware, installed tools, and material configuration. Tech Pack OS therefore treats file generation as a reviewed handoff, not a one-click guarantee, and makes simulation and controller-specific post-processing part of the workflow.

## Outcome

Tech Pack OS is in active development with the core engineering loop working: capture garment evidence, distinguish facts from assumptions, edit structured construction, validate geometry, draft semantic pattern pieces, and prepare production handoff files. The rebrand makes the product's purpose clearer and gives studios a more trustworthy operating model for AI-assisted apparel specifications.
